# REDESIGN COMPLETO DO HARMONIC

Quero que você faça um redesign completo do aplicativo Harmonic.

## Objetivo

Transformar o Harmonic em um aplicativo com a mesma sensação de qualidade, fluidez e refinamento do Spotify, porém utilizando a identidade visual do Harmonic.

O objetivo NÃO é copiar o Spotify, mas utilizar seus princípios de UX, UI e Design System para criar uma experiência premium.

Mantenha absolutamente todas as funcionalidades existentes.

NÃO altere:

- lógica
- banco de dados
- APIs
- rotas
- algoritmos
- processamento
- estrutura dos componentes
- regras de negócio

Toda alteração deve ser exclusivamente visual.

--------------------------------------------------------

# TIPOGRAFIA

Utilize exclusivamente a fonte **Plus Jakarta Sans** em todo o aplicativo.

Importe a fonte corretamente (Google Fonts ou equivalente) e aplique-a globalmente através do Theme do projeto.

Não utilize outras famílias tipográficas, exceto ícones quando necessário.

A tipografia deve transmitir:

- Sofisticação
- Tecnologia
- Clareza
- Modernidade
- Elegância
- Produto premium

Utilize apenas estes pesos:

500 (Medium)

600 (SemiBold)

700 (Bold)

Evite excesso de pesos diferentes.

Nunca utilize fontes arredondadas, infantis ou decorativas.

# ORGANIZAÇÃO DO CÓDIGO

Shadow Tokens

Motion Tokens

Opacity Tokens

Breakpoint Tokens

Utilize esses tokens em todo o projeto.
