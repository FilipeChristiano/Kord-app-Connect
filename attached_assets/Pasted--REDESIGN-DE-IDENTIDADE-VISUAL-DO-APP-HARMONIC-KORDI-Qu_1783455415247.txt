Quero alterar a identidade visual do aplicativo de **Harmonic** para **Kordi**.

Não altere funcionalidades, lógica, banco de dados, rotas, autenticação ou APIs.

A alteração deve ser apenas de:

* identidade visual
* nome do app
* logo
* cores
* branding
* textos institucionais
* assets visuais
* favicon/app icon
* pequenos ajustes de UI para combinar com a nova marca

# 1. NOVO NOME

Substituir todas as ocorrências visuais de:

Não alterar nomes técnicos internos se isso puder quebrar o sistema.
Se existirem variáveis, tabelas, rotas ou arquivos com “harmonic”, só alterar se for seguro.
